CpuPLFix —— 开机/睡眠唤醒后 CPU 被锁 0.55GHz 的自动修复工具
==============================================================

【症状】

笔记本开机后、或者睡眠唤醒后，CPU 频率被锁在很低的水平（常见 0.55GHz / 0.8GHz / 1.0GHz），
风扇不转、温度不高，但什么都卡。重启或者进 ThrottleStop 手动点一下能好，下次又犯。


【原因】

Intel 平台的"封装功耗墙"(PL1 长时 / PL2 短时)在硬件里存了两份镜像：

    1) MSR 0x610          —— CPU 内部寄存器，Windows 和 ThrottleStop 用的是这一份
    2) MCHBAR + 0x59A0    —— 主板/EC 固件用的那一份(MMIO)，bit63 是"锁定位"

正常情况下两份应该一致。但有些机器(尤其是某些 Lenovo / 蓝天模具 / 工程样品 CPU)的固件
会在开机和唤醒时把第二份(MMIO)改成一个很小的值，CPU 就被钉在最低频。

在 ThrottleStop 里勾选 TPL 窗口的 "MMIO Lock" 之所以能修好，就是因为它把正常值写回
MMIO 再把 bit63 置 1。锁上之后固件再也改不动，所以必须重启才能恢复原样。

本工具做的是同一件事，只是不需要图形界面、开机就能自动跑。


【怎么用】

    1. 把整个文件夹解压到任意位置（路径别带空格更省事）
    2. 双击 1-install.bat
    3. 弹出"用户账户控制"时点"是"
    4. 看到 [√] 已生效 就装好了

之后不用管。开机后 15 秒、睡眠唤醒后 4 秒，它会自动检查并修复。

其它脚本：

    2-check.bat      查看当前状态（两份功耗墙的值、频率、是否已锁定）
    3-fix-now.bat    立即修复一次
    9-uninstall.bat  卸载（删除计划任务和驱动服务，不删文件）


【要求】

    - Intel CPU（AMD 没有这套寄存器）
    - Windows 10 / 11，64 位
    - 安装时需要管理员权限

不需要安装 ThrottleStop，驱动已经内置在本目录的 TSCtl.sys 里。


【关于驱动】

读写 MSR 和物理内存必须有内核驱动。本工具已内置 TSCtl.sys，安装时复制到工具目录
并注册成服务 TSCtl，之后由计划任务按需拉起。

这个驱动来自 ThrottleStop（作者 Kevin Glynn）。ThrottleStop 把它内嵌在自己的 exe 里，
本工具按 PE 结构把 x64 镜像连同数字签名一起提取出来，一个字节都没改，只换了个文件名
（否则会和 ThrottleStop 自己的设备名冲突）。

装好本工具后可以直接卸载 ThrottleStop，两者互不影响 —— 驱动文件在工具目录下，
服务名 TSCtl，跟 ThrottleStop 的临时驱动没有任何关联。

已知限制：如果机器开了"内核隔离 / 内存完整性"(HVCI)，Windows 可能拒绝加载这类直接
访问物理内存的驱动，安装会失败。需要先关掉内存完整性再装。


【会不会把 CPU 烧了】

不会。工具的原则是"镜像系统自己的设置"，不是"超频"：

    - 如果 MSR 里的 PL1 是正常值，就原样写进 MMIO，一个瓦都不改
    - 只有 MSR 本身也被压坏（低于 15W）时，才用 CPU 标称 TDP 兜底

而且 CPU 自身的热保护（温度墙、EDP 电流墙）完全不受影响，该降频还是会降频。

想手动指定功耗墙，编辑 config.json：

    pl1_w      长时功耗墙(瓦)，填 0 = 自动
    pl2_w      短时功耗墙(瓦)，填 0 = 自动
    min_pl1_w  判定"MSR 被压坏"的阈值，默认 15
    lock_mmio  是否锁死 MMIO，默认 true

注意：MMIO 一旦锁定，要重启才会解除。所以想连续调参的话，先把 lock_mmio 设为 false。


【日志】

    logs\fix.log    每次运行的完整记录，含修复前后的数值。
    反馈问题时把这个文件带上。


【卸载】

    9-uninstall.bat

只删除计划任务和驱动服务，不动文件，也不影响 ThrottleStop 本身。


【已知限制】

    - 只处理 PL1/PL2 这一条路径。如果是 BD PROCHOT、温度墙、电池/适配器识别问题
      导致的降频，本工具管不了，那种情况还是得用 ThrottleStop 排查。
    - 不同机器 MMIO 的功耗墙寄存器偏移可能不同。本工具按 0x59A0 处理（Intel 近几代通用）。
      如果你的机器不是这个偏移，2-check.bat 会显示读不到或数值明显不对。
